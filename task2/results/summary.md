# Experiment results

Generated by `python experiments.py`.

- A *ply* is one move of one player. One game cycle = 2 plies (MAX moves, then MIN moves).
- **Nodes** = game-tree nodes visited (MAX nodes + MIN nodes, root included). This is the measure of time complexity; seconds are given next to it.
- **b\*** = effective branching factor: the b for which a uniform tree of the same depth has the same number of nodes, `nodes = 1 + b* + b*^2 + ... + b*^m`.
- **Max ply** = deepest level reached. Depth-first search keeps one path in memory, so space is O(b·m) and grows with this number, not with the number of nodes.
- Per-search time budget: 30.0s.
